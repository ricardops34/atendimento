# PoSearchAiLiterals

**Tipo:** Interface / Modelo
**Pacote:** `@po-ui/ng-components`
**Referência:** https://po-ui.io/documentation/po-search-ai-literals

Interface para definição das literais usadas no `po-search-ai`.

## Propriedades

| Propriedade | Tipo | Opcional | Descrição |
|---|---|---|---|
| `clean` | `string` | sim | Texto de acessibilidade do botão de limpar o campo. |
| `errorMessage` | `string` | sim | Mensagem exibida quando a busca com IA falha. |
